# Shannon J. Love — Combined Resume

Dark Editorial Luxury single-page resume with live links to TV reels and writing samples.

## Development

```bash
cd combined-resume
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploy the `dist/` folder to **resume.shannonjeffreylove.com**.

## Identity notes for builders

- **Shannon J. Love is male (he/him).** Never use she/her in copy.
- **Visuals:** Use only official YouTube video thumbnails (`img.youtube.com/vi/{ID}/hqdefault.jpg`) — no stock photos or portrait headshots.

## Sections

- Hero with embedded highlight reel
- About + stats + network marquee
- TV & Broadcast Work (12 clickable YouTube credits)
- The Pen — Writing & Speech (6 hosted samples + Medium/Inkwell)
- Experience timeline, expertise, awards, education
- Contact + ecosystem cross-links
